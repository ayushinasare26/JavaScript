# 🚀 Online Job Application Form

A modern, interactive job application form with real-time validation and an attractive UI design.

## ✨ Features

- **Real-time Validation** - Instant feedback as users type
- **Modern UI Design** - Beautiful gradient backgrounds and smooth animations
- **Responsive Layout** - Works perfectly on desktop, tablet, and mobile devices
- **Visual Feedback** - Color-coded validation states (green for valid, red for errors)
- **Smooth Animations** - Hover effects, shake animations, and floating elements
- **Professional Color Scheme**:
  - Primary: Coral Red (#ff6b6b) & Turquoise (#4ecdc4)
  - Secondary: Sky Blue (#45b7d1) & Mint Green (#96ceb4)
  - Background: Dark Navy Gradient (#1a1a2e to #0f3460)

## 📋 Form Sections

1. **👤 Personal Information**
   - Full Name, DOB, Gender, Email, Mobile, Address, City, State, PIN Code

2. **🎓 Educational Qualification**
   - Highest Qualification, University/Institute, Passing Year, Percentage/CGPA

3. **💼 Professional Information**
   - Job Position, Work Experience, Organization, Designation, Expected Salary

4. **⚡ Technical Skills**
   - Programming Languages, Technical Skills, Certifications

## 🎨 Color Palette

- **Coral Red**: #ff6b6b - Primary action buttons
- **Turquoise**: #4ecdc4 - Secondary buttons & accents
- **Sky Blue**: #45b7d1 - Tertiary accents
- **Mint Green**: #96ceb4 - Success states
- **Navy**: #1a1a2e - Background
- **White/Light**: #ffffff - Form background

## 🚀 Getting Started

Simply open `index.html` in your web browser to use the form!

## 📱 Responsive Design

The form automatically adapts to different screen sizes:
- Desktop: Full-width layout with side-by-side buttons
- Tablet: Optimized spacing and touch-friendly inputs
- Mobile: Single-column layout with stacked elements

## ✅ Validation Rules

- Email must be valid format
- Mobile number: 10-15 digits
- Age: Must be 18+
- PIN Code: 5-6 digits
- Names: Letters and spaces only
- All required fields must be filled

## 🎯 Technologies Used

- HTML5
- CSS3 (Modern features: Grid, Flexbox, Animations)
- Vanilla JavaScript (No frameworks required)
- Google Fonts (Poppins)
